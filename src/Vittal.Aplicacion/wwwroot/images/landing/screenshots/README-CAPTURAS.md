# Guía de Capturas de Pantalla - Landing Page Vittal

## Instrucciones

1. Inicia sesión en el sistema: `http://localhost:5218/Login/Auth/Login`
2. Navega a cada URL indicada abajo
3. Captura pantalla completa (F12 → Toggle Device Toolbar → 1920×1080)
4. Guarda el archivo con el nombre exacto indicado
5. Todos los archivos van en esta carpeta: `wwwroot/images/landing/screenshots/`

## Screenshots Requeridos

### 1. Dashboard (Hero principal)
- **URL:** `http://localhost:5218/Dashboard/Dashboard`
- **Nombre:** `dashboard.png`
- **Uso:** Hero de la página principal (Index)

### 2. Expedientes (Módulo central)
- **URL:** `http://localhost:5218/Expedientes/Expedientes`
- **Nombre:** `expedientes.png`
- **Uso:** Galería de Funcionalidades

### 3. Agenda (Calendario)
- **URL:** `http://localhost:5218/Agenda/Agenda`
- **Nombre:** `agenda.png`
- **Uso:** Galería de Funcionalidades

### 4. Cola de Espera (Tiempo Real)
- **URL:** `http://localhost:5218/ColaEspera/ColaEspera`
- **Nombre:** `cola-espera.png`
- **Uso:** Galería de Funcionalidades

### 5. Pacientes (Catálogo)
- **URL:** `http://localhost:5218/Catalogos/Paciente`
- **Nombre:** `pacientes.png`
- **Uso:** Galería de Funcionalidades

### 6. Reportes (Analítica)
- **URL:** `http://localhost:5218/Reportes/Reportes`
- **Nombre:** `reportes.png`
- **Uso:** Galería de Funcionalidades

## Formato Recomendado

- **Dimensiones:** 1920×1080 px (Full HD)
- **Formato:** PNG (mejor calidad para UI)
- **Tamaño máximo:** 500 KB por imagen (comprimir si es necesario)
- **Herramienta sugerida:** Chrome DevTools (F12) → Device Toolbar → Responsive → 1920×1080

## Notas

- Los archivos SVG placeholder serán eliminados después de agregar los screenshots reales
- Si una imagen no carga, se mostrará el placeholder SVG actual
- Las imágenes se comprimen automáticamente al desplegar (optimize-images.ps1)
